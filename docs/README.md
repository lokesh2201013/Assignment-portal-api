# Assignment Portal Documentation

This page is the documentation index for the services in this workspace. Service routes and schemas are the source of truth; older examples elsewhere in the repository may describe legacy paths.

| Service | Interactive API docs | OpenAPI source | Database / setup |
|---|---|---|---|
| Assignment API | `http://localhost:8080/docs` | [OpenAPI](../Assignment-api/assignment-portal/docs/openapi.yaml) | [Service guide](../Assignment-api/assignment-portal/docs/README.md), [database](../Assignment-api/assignment-portal/docs/database.md) |
| RAG service | `http://localhost:8001/docs` | [OpenAPI](../RAG-service/docs/openapi.yaml) | [Service guide](../RAG-service/README.md), [database](../RAG-service/docs/database.md) |
| Email service | `http://localhost:3000/docs` | [OpenAPI](../email-microservice/docs/openapi.yaml) | [Service guide](../email-microservice/docs/README.md), [database](../email-microservice/docs/database.md) |
| Video service | `http://localhost:5000/docs` | `GET /openapi.json` generated by FastAPI | [Service guide](../video-service/README.md), [database](../video-service/docs/database.md) |

The Go services serve their OpenAPI YAML at `GET /openapi.yaml`. Their Swagger UI pages use the Swagger UI CDN, so the browser needs internet access to load the UI assets; the YAML URL itself is served locally. Video’s FastAPI Swagger UI and OpenAPI JSON are generated from its registered HTTP routes. WebSocket routes are documented in the Video service guide because OpenAPI does not model WebSockets.

## Local prerequisites

- Go versions declared by each service's `go.mod`.
- Python 3.10+ and the Video service virtual environment/dependencies.
- PostgreSQL. Assignment API, RAG, and Email create their own tables on startup; Video expects its `videos` table to be created from its schema file.
- Qdrant and Ollama for RAG, SMTP credentials for Email, and Google Cloud Storage credentials plus ClamAV for upload workflows.
- Jaeger or an OTLP HTTP collector listening at the configured endpoint to view traces.

See each service guide for required environment variables and exact run/test commands. Do not use production credentials in local `.env` files committed to source control.
